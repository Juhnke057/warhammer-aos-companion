# AoS Spearhead Companion

A tablet companion app for **Warhammer: Age of Sigmar — Spearhead** format games. Built to run on an iPad or Android tablet lying flat between two players, replacing paper army rosters and scoresheets.

> **This project is vibe-coded and AI-generated.**
> Built with Claude Code (Anthropic) through natural-language conversation — no traditional development workflow. Every component, design decision, and line of code was generated by Claude based on user prompts.

---

## What it does

- Tracks HP (wound boxes) for every unit on both sides simultaneously
- Manages Victory Points with a gothic +/− counter per player
- Guides players through each battle phase (Round Start → Hero → Movement → Shooting → Charge → Combat → End)
- Draws and displays Twist Cards (Aqshy / Ghyran realm effects)
- Handles faction-specific mechanics:
  - **FEC** — Noble Deeds tracker, Summon Loyal Subjects buttons
  - **Skaven** — Lurking Vermintide reserve deadline warning
  - **Stormcast** — Vigilant Brotherhood Holy Orders once-per-battle abilities
- Status effect system (Frenzied, Ensnared, Strike-First, Ward saves, etc.)
- Warscroll viewer for each unit (stats, weapons, abilities)
- Battle Tactics card hand
- In-app PDF rulebook viewer
- Pre-battle setup checklist (terrain, deployment, realm selection)

## Design

The UI uses a **Parchment Codex** aesthetic:

- Warm cream/parchment backgrounds tinted per faction (crimson for FEC, green for Skaven, gold for Stormcast)
- Cinzel serif font for all headings and labels
- Faction-specific edge art SVG strips (skull tracery for FEC, claw marks for Skaven, lightning sigils for Stormcast)
- Unique hand-drawn SVG silhouette icons for every unit
- Dark aged-wood center strip with gold accents
- HP wound boxes (checkbox grid) replacing numeric health bars

## Building for Android

### Prerequisites

- [Android Studio](https://developer.android.com/studio) (includes Java 21 JBR)
- Android SDK API 35+
- Node.js 18+

### Steps

```bash
# 1. Build the web app
npm run build

# 2. Set environment variables (Git Bash)
export ANDROID_HOME="$USERPROFILE/AppData/Local/Android/Sdk"
export JAVA_HOME="C:/Program Files/Android/Android Studio/jbr"
export PATH="$ANDROID_HOME/cmdline-tools/latest/bin:$ANDROID_HOME/platform-tools:$PATH"

# 3. Sync web assets to Android project
npx cap sync android

# 4. Open in Android Studio and run on emulator/device
npx cap open android
```

In Android Studio: **Build → Clean Project**, then press **Run ▶**.

> The app is designed for landscape orientation on tablets (tested on Galaxy Tab S10 FE+ emulator, API 35).

## Adding New Factions

1. Create `src/data/yourfaction.js` following the structure in `fec.js`
2. Add faction colors to `src/themes/factionThemes.js`
3. Add unit icons to `src/components/ui/UnitIcons.jsx`
4. Register in `src/store/gameStore.js` and `src/components/setup/SetupScreen.jsx`
